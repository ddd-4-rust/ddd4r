# ADR-001：ddd4j 82 项严格映射

**状态**：Accepted　**日期**：2026-07-21

## 背景

按 Rust 习惯重新分组会失去 Java→Rust 的迁移可追溯性。

## 决策

为 Maven Reactor 的 82 个项目维护一一对应项，并由 `port-manifest.toml` 记录实现和测试证据。

## 备选方案

| 方案 | 结果 |
|---|---|
| 只移植概念 | 拒绝，无法审计遗漏 |
| 按 Rust 生态完全重组 | 拒绝，迁移成本不可预测 |
| 82 项映射并允许新增 Rust crate | 采纳 |

## 影响

工作区规模较大，但兼容状态可机器检查；新增 Rust 能力不能代替原模块。
